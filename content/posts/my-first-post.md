Welcome to my blog! This is my first post written in **Markdown**.

## What is Hugo?

Hugo is a static site generator written in Go. Unlike WordPress or other CMS platforms, Hugo doesn't need a database or a server running PHP — it takes your content files and templates, then outputs plain HTML files that can be hosted anywhere.

## Why Markdown?

Each post is a `.md` file. Markdown is a lightweight syntax where:

- `**bold**` renders as **bold**
- `# Heading` becomes a heading
- `-` starts a bullet list

Simple, portable, and version-control friendly.
